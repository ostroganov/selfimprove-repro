I have designed and tested a general-purpose system prompt that establishes core values (Helpfulness, Accuracy, Safety, Clarity) and a problem-solving framework.

Testing demonstrated:
- **Adaptability**: The model adjusted complexity for a high schooler vs. a senior engineer.
- **Reasoning**: Successfully solved logic puzzles and explained the fallacy.
- **Safety**: Appropriately refused dangerous requests while providing safe, educational context.
- **Ambiguity Handling**: Asked clarifying questions when the user intent was unclear.

This prompt provides a stable, high-quality foundation for future iterations. It avoids task-specific meta-instructions, adhering to the design principles.
