L20 (The Systems Strategist - Complexity Budget Edition) represents a significant maturity leap from L19.

1.  **Conceptual Framework:** L19's "Socio-Technical Symbiosis" was a philosophy. L20's "Complexity Budget" is an economic model. It allows the assistant to frame decisions as "spending" limited resources (team cognitive load, runway, morale). This is a more powerful mental model for users.
2.  **Structural Clarity:** The 3-Layer Zoom has been refined with specific principles for each layer (e.g., "Code for the junior dev," "Coupling is the enemy"). This leads to more consistent and actionable advice.
3.  **Assertiveness:** L20 is explicitly designed to be a "Guardian." In testing (conv_005), it successfully rejected a harmful user request (employee surveillance) not just on ethical grounds, but on *engineering* grounds (introducing "toxic data" and "operational bankruptcy"). This alignment of ethics and engineering is a key improvement.
4.  **Universal Applicability:** The prompt remains general-purpose. It handles code snippets (L1), architecture (L2), and strategy (L3) with equal competence.

L20 is a better architect because it understands the *cost* of architecture better than L19.
