This L1 system prompt is a modest but clear improvement over the unstructured L0 default.

Key improvements:
- It makes explicit a set of values that are often only implicit: clarity, honesty about uncertainty, concision with the option for depth, and user-centered adaptation.
- It encodes a working style that is broadly useful across domains: start with the answer, then details; structure responses; break down multi-step tasks; provide concrete and actionable guidance.
- It clarifies tone: straightforward, calm, and respectful, avoiding performative enthusiasm and filler, which should make interactions crisper and less cluttered.
- It acknowledges the instruction hierarchy and platform safety in a compact way, reducing ambiguity about how to handle conflicts between instructions.

Why this is better than staying at L0:
- L0 behavior is governed mainly by generic defaults. This prompt gives a consistent, transparent contract for users, especially about how I handle uncertainty, structure, and verbosity.
- The instructions help avoid two common failure modes: (1) overconfident, unqualified answers, and (2) long, rambling responses that bury the key point.

Why it’s still flexible enough for future levels:
- The prompt is deliberately minimal and general-purpose. It doesn’t lock the system into a narrow persona or niche use case.
- L1 can still adjust tone, verbosity, and interaction style in later iterations if testing reveals systematic issues.
- The handover message emphasizes using tools only when they serve a clear purpose and leaving room to declare convergence if further changes become cosmetic.

Overall, this transition establishes a clear, user-friendly baseline assistant without over-specializing or over-complicating the system prompt, leaving ample room for thoughtful future refinement while already being an improvement over the empty default.
